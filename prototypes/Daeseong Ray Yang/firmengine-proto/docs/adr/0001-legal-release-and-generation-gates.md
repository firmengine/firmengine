# 법령 배포판 검토와 서류 생성 조건을 별도로 확인한다

법령 원문의 수집이나 일부 금액 산식의 회귀검증만으로 사건에 적용할 법률 조건 전체가 검토되었다고 판단할 수 없으므로, 기본 `seoul-blueprint-arithmetic-v1` 배포판은 `REVIEW_REQUIRED`로 둔다. 사건의 신청일·관할에 적용할 배포판을 명시적으로 검토하고 `rule_release_id`와 `calculator_release_id`를 연결한 경우에만 해당 범위의 생성 조건을 판단한다. 자동 법령 감시가 채무한도 변수만 검증한 경우에는 그 변수의 출처·해시·시행일·버전만 계산에 반영하며 전체 배포판의 승인 상태를 바꾸지 않는다.

필수 법률·증빙 조건과 필수 출력 기재값이 미해결이면 법원 서류 생성을 보류한다. 생성 파일의 부재, 편철 확인, 서명·날인은 생성 후 패키지 완성 단계에서 확인하므로 파일을 만들기 전이라는 이유로 생성이 불가능해지는 순환을 만들지 않는다. 비필수 경고는 위험 이력에 남겨 초안과 함께 제공하고, 생성 완료를 법원의 인가 가능성이나 실제 제출 완료로 표시하지 않는다.

`case_engine.evaluate_case`는 법률·증빙 범위의 게이트, `rendering.court_package`는 출력 기재값·템플릿과 생성 후 패키지의 상태를 제공한다. 기본 배포판의 상태를 일괄 `APPROVED`로 바꾸거나 모든 경고를 강제 통과시켜 테스트를 맞추지 않는다. 전체 법률 예외·보정 사유를 자동 판정하는 구현은 아니므로, 수동 검토 항목과 구현 범위를 함께 유지한다.
