# FirmEngine 기능 테스트 프론트엔드

React 19·Vite 8로 만든 로컬 업무 흐름 테스트 화면입니다. 의뢰인·담당자·변호사 관점에서 같은 가상 사건의 상담, 자료 요청, 원문 확인, 계산, 문서 검토를 이어서 확인합니다.

기존 [ax-site](../ax-site/)와 별도 앱이며 사건 처리용 서버 API·OCR·외부 모델을 호출하지 않습니다. 사이드바의 날씨·시세·뉴스만 공개 데이터를 조회합니다. 역할 전환은 인증이나 실제 접근 권한 검증을 대신하지 않습니다.

## 실행

Node.js 22.13 이상이 필요합니다. 저장소 루트에서 실행합니다.

```powershell
cd "prototypes/Daeseong Ray Yang/firmengine-proto/frontend-lab"
npm.cmd install
npm.cmd run dev
```

브라우저에서 [http://localhost:5173](http://localhost:5173)을 엽니다. `start-local.cmd`를 실행해도 됩니다. 포트가 사용 중이면 `npm.cmd run dev -- --port 5174`처럼 다른 포트를 지정할 수 있습니다. 관리자 화면은 [http://localhost:5173/#/admin](http://localhost:5173/#/admin)입니다. macOS/Linux에서는 `npm.cmd` 대신 `npm`을 사용합니다.

```powershell
npm.cmd run build
npm.cmd run test
```

`build`는 TypeScript 검사와 배포 파일 생성을, `test`는 로컬 상태 모델 검사를 실행합니다. 실제 업무 인수나 OCR 정확도 검사를 의미하지 않습니다.

## 확인 순서

1. 정상·필수 누락·금액 충돌 프리셋 중 하나를 선택합니다. 모두 허구의 합성 사건입니다.
2. 의뢰인 관점에서 상담과 준비 서류의 대상·기간을 확인하고 파일을 추가합니다.
3. 담당자 관점에서 자료 상태와 모의 추출값·원문 근거를 확인합니다. 값 정정에는 사유를 남깁니다.
4. 월 소득·생계비·비용과 선택한 36·48·60개월에 따른 예시 계산, 남은 작업을 확인합니다.
5. 문서 스냅샷을 만들고 담당자 검토 후 변호사 검토를 진행합니다. 입력을 바꾸어 재검토가 필요한지도 확인합니다.
6. JSON 또는 HTML 보고서를 내려받아 현재 스냅샷과 비교합니다. 세부 시나리오는 [기능 테스트 계획](docs/functional-test-plan.md)에 있습니다.

파일 선택은 메타데이터 연결과 로컬 미리보기용입니다. 모의 추출은 준비된 fixture를 불러오며 선택한 파일을 읽어 값을 추출하지 않습니다. 실제 의뢰인 자료 대신 가상 파일만 사용하세요.

## 구현 범위와 명세 대응

| 요구사항 | 로컬에서 확인하는 동작 | 별도 검증·구현이 필요한 범위 |
| --- | --- | --- |
| F1 상담·필요서류 | 상담 편집, 조건에 따른 요청 목록, 자료의 대상·기간·상태 | 실제 상담 모델 분류, 법령·관할별 요구의 정확성 |
| F2 추출·원문 대조 | 합성 추출값과 출처 표시, 누락·충돌 상태, 사유를 남긴 정정 | 실제 PDF·이미지 OCR, 원문 위치·인용의 실물 검증 |
| F3 계산 | 명시한 예시 입력에 대한 결정론적 산술과 기간 선택 | 실제 법률 산식·생계비·청산가치·채권 배분의 적합성 |
| F4 근거·변경 추적 | 사건 변경 이력, 자료와 사실의 연결, 검토 상태 갱신 | 실제 Law-Graph·공식 출처 검색, 서버 판본·동시 수정·저장 복구 |
| F5 문서 생성·출력 | 고정된 문서 스냅샷, 과거본 보존, JSON·HTML 보고서 | 공식 법원 DOCX·XLSX 생성, 전자소송 양식 대조·제출 |
| F6 생성 후 HITL | 담당자 → 변호사 검토 순서와 입력 변경 후 재검토 | 실제 사용자 인증·직무 권한, 전문 검토·법적 승인 |

36·48·60개월은 기능 테스트용 선택지입니다. 해당 기간이 실제 사건에 허용되거나 계산 결과가 법적으로 인정된다는 뜻이 아닙니다. 보고서 다운로드와 화면의 검토 완료도 법원 제출·접수·인가를 의미하지 않습니다.

## 저장과 초기화

가상 사건 상태는 현재 브라우저의 로컬 저장소에 보관합니다. 새로고침 후에도 테스트를 이어갈 수 있으며 초기화하면 기본 예제로 돌아갑니다. 서버·다른 브라우저와 동기화하지 않습니다. 선택한 파일의 바이트와 로컬 미리보기는 영구 사건 보관 기능이 아니므로 새로고침 후 다시 선택해야 할 수 있습니다.

이 앱은 v44의 업무 흐름을 가볍게 확인하기 위한 시뮬레이션입니다. 실제 저장소 장애, OCR·법률 판단 정확도, 공식 서식 일치, 다중 사용자 권한 검사는 포함하지 않습니다.

## 합성 PDF 원문

`public/demo/`의 `identity.pdf`, `income.pdf`(2쪽), `debt.pdf`, `business.pdf`, `asset.pdf`, `debt-alt.pdf`는 원문 뷰어·페이지 연결·표시 편집을 확인하기 위해 로컬에서 만든 실제 PDF입니다. 모든 페이지와 PDF 메타데이터에 합성 예시임을 표시합니다. 한글 글꼴을 대체하지 않도록 PDF 본문은 영문이며, 수입 450만 원·경비 30만 원·생계비 180만 원·채무 7,200만 원(상충 대안 8,400만 원)·재산 300만 원은 상태 모델의 고정 예시와 같습니다.

다음 명령은 외부 자료나 API 없이 이 파일들과 출처 목록 `public/demo/manifest.json`을 다시 만듭니다.

```powershell
node scripts/create-demo-pdfs.mjs
```

PDF 뷰어의 형광 표시와 회전은 내려받는 사본에만 반영됩니다. 페이지별 메모는 별도 JSON으로 저장하며 원본 파일은 바꾸지 않습니다. 이 PDF에서 실제 OCR을 수행하거나 추출 정확도를 측정하지 않습니다.

## 화면과 일상 정보

`debtoff/apps/office`의 사건 중심 구성·색상·서체와 고객 포털의 숲 사진을 반영했습니다. 사이드바는 `100dvh`, 메뉴만 스크롤하고 정보 영역은 하단에 유지합니다. 화면·카드·버튼·숫자·PDF 로딩·알림 효과는 OS의 동작 줄이기 설정을 따릅니다. 사진은 기존 `debtoff`의 로컬 자산이며 [출처](public/images/credits.json)를 함께 보관합니다.

- 점심: 기기에서 메뉴를 무작위로 골라 지도 검색에 연결합니다. 실제 식당의 평점·영업 상태를 조회하는 추천은 아닙니다.
- 날씨: [Open-Meteo](https://open-meteo.com/en/docs). 기본 위치는 서울, 위치 버튼을 누르고 브라우저에서 허용하면 현재 위치를 사용합니다. 좌표는 조회에만 사용하고 저장하지 않습니다. 무료 제공 범위는 [제공사 요금 안내](https://open-meteo.com/en/pricing)를 따릅니다.
- 시세: Yahoo 공개 차트 조회. [거래소별 지연 안내](https://help.yahoo.com/kb/SLN2352.html)에 따라 시각과 출처를 표시합니다. 비공식 엔드포인트로 서비스 보장은 없습니다.
- 뉴스: [연합뉴스 RSS](https://www.yna.co.kr/rss/index), 실패 시 [BBC 한국어 RSS](https://github.com/bbc/world-service-rss/blob/main/korean.md). 제목만 순환 표시하고 원문에 연결합니다.

정보는 6초마다 순환하며 마우스·키보드 포커스·일시정지 버튼·동작 줄이기 설정에서 멈춥니다. 조회 실패와 이전 캐시 사용은 구분해 표시합니다. 공개 정보 중계는 Vite의 로컬 개발/미리보기 서버에서 동작하므로 `dist`만 다른 정적 서버에 올리면 별도 중계 구현이 필요합니다. `npm.cmd run preview`로 빌드 결과와 중계를 함께 확인할 수 있습니다.

## 관리자와 기능 확인

기준정보 관리자에서 v44 공개 기준의 6개 스키마·54개 레코드를 확인하고, 로컬 편집본 CRUD·JSON 가져오기/내보내기·판본 제안·확인·복원을 시험합니다. 원본 보호 레코드는 복사하여 편집합니다. 샘플 집합이며 운영 기준 전체 DB를 대체하지 않습니다. [기능 대응표](docs/feature-coverage.md)와 [수동 테스트](docs/functional-test-plan.md)를 참고하세요.

검증: TypeScript·프로덕션 빌드, 상태 모델·관리자·PDF 좌표 회귀검사, 실제 Chromium의 정상 사건 생성·검토·HTML 다운로드·정정 후 재검토, PDF 표시·회전·형광표시·사본 다운로드를 확인했습니다. 실제 OCR·법률 정확도·운영 인증·공식 DOCX/XLSX 생성은 별도 AX API 연결 범위입니다.
