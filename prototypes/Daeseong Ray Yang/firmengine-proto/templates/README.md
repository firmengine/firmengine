# 편집형 법원 서식

`D5100`, `D5106`, `D5101`, `D5103`, `D5105`, `D5110` DOCX는 함께 보관한 법원 공개 PDF/HWP의 구역·항목을 편집 가능하게 재구성한 초안입니다. 원본과 동일한 페이지 배치나 최신 접수 적합성을 보장하는 변환본이 아닙니다. 실제 법원에서 받은 양식과 필드 매핑을 검토한 뒤 사용합니다.

- `originals/`: 출처 카탈로그의 SHA-256과 대조하여 보관한 공개 빈 원본. 실제 의뢰인의 자료나 제출본을 포함하지 않습니다.
- `catalog.json`: 원본 URL, 수집일, SHA-256, 템플릿 버전·해시, 매핑된 필드와 검토 상태.
- `*.docx`: `{{client_name}}` 같은 단순 토큰. `{{creditor.*}}`, `{{asset.*}}`, `{{month.*}}` 행은 실제 자료 수만큼 반복됩니다.
- `build_templates.py`: 이 디렉터리에 보관한 원본과 카탈로그에서 편집형 템플릿을 다시 만드는 개발 도구. 외부 참고 프로젝트에 의존하지 않습니다. 재실행하면 템플릿 편집 내용이 덮어써지므로 변경한 양식은 먼저 보관해야 합니다.

토큰은 코드나 표현식으로 실행하지 않습니다. 누락은 `[확인 필요]`, 충돌은 `[불일치·확인 필요]`, 여러 기간을 하나로 정할 수 없으면 `[기간 선택 필요]`로 남깁니다. 서명·동의·법률 판단 선택란은 자동 확인하지 않습니다. 동일 채권자의 여러 기간을 합산하거나 36개월을 기본값으로 채우지 않습니다.

템플릿을 변경하면 대응 항목을 검토한 뒤 `catalog.json`의 템플릿 버전과 SHA-256도 갱신해야 합니다. 해시가 달라진 파일은 렌더러가 거부합니다. 각 출력본에는 별도 출처·검토 대조표가 붙습니다. 채권 우선순위·담보·특수 부속표와 채권자별 배분 등 아직 구조화되지 않은 항목은 확인 필요로 남습니다.

XLSX의 금액과 산식은 값·정밀도·출처 보존을 위해 텍스트로 기록합니다. 외부 문서에서 온 `=...` 문자열을 엑셀 수식으로 실행하지 않습니다. 출력물을 외부에서 수정한 내용은 앱의 검토 승인에 자동 반영되지 않습니다.
