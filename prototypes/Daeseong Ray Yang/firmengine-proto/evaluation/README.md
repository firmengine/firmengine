# 평가 자료 관리

이 폴더에는 평가 코드와 합성 회귀검사만 보관합니다.
실제 샘플 PDF, 페이지 분리표, 정답, 사례별 평가 결과는 공개 저장소에 포함하지 않습니다.

개별 자료를 평가하려면 승인된 원본과 검토한 설정을 Git에서 제외된 `.runtime/evaluation/`에 별도로 준비해야 합니다. 기본 샘플은 제공하지 않습니다.

- `sample_manifest.json`: 원본 확인값, 전체 페이지 수, 증빙·평가·제외 페이지, `extraction_batches`.
- `source.pdf`: 승인된 입력 원본. 생성기는 증빙 페이지만 받습니다.
- `submission_rubric.json`: 해당 입력에 대해 별도로 확정한 문서별 평가 기준.
- 실행 결과·정답·비교 보고서는 같은 비공개 작업 폴더에 저장합니다.

설정이 없으면 샘플 실행은 중단됩니다. 저장소의 합성 테스트는 실제 사건이나 법원 제출 적합성 평가를 대신하지 않습니다.
