# FirmEngine AX

의뢰인이 제출한 서류를 사건 자료로 정리하고, 필요한 계산과 검토를 거쳐 법원 서류 초안을 만드는 업무 공간입니다.

현재 기준은 **v44**입니다. v43 작업본에서 이어서 수정했으며, 기존 비공개 사이트에 배포했습니다.

## 주요 기능

- 상담 내용을 사건별 준비 서류와 담당자 작업으로 연결합니다.
- 서류에서 확인한 값과 원문 위치를 함께 보관합니다.
- 소득·채무·재산·생계비가 바뀌면 계산과 검토 상태를 다시 확인합니다.
- 서로 다른 값, 부족한 자료, 사람의 판단이 필요한 항목을 구분합니다.
- 신청서, 채권자목록, 재산목록, 수입·지출목록, 변제계획과 일정을 작성합니다.
- 담당자 검토와 최종 작성 조건을 구분하고, 이전 파일과 변경 이력을 보존합니다.

## 사건별 상담 서류·피처 계획 (코드 변경, 운영 적용 전)

상담 완료 시 사건별 서류 요구와 원문 확인 항목·OCR 후보 스키마를 함께 보관하는 변경을 추가했습니다. 접수·OCR 상태는 별도 이벤트로 감시하며, 갈음서류 관계 로직은 변경하지 않았습니다. **운영 DB 마이그레이션·배포 및 실제 통합 검증은 아직 별도 작업입니다.**

## 현재 확인된 범위

회귀 테스트 950개와 합성 사건 52건의 비교 1,397개를 통과했습니다. Word 문서 463개와 Excel 파일 52개를 생성해 내용 구조를 확인했고, 대표 Word 문서 24개·214쪽은 화면으로 검수했습니다.

공식 전자소송 서식과의 항목별 대조, 실제 담당자의 전체 사용 검증은 남아 있습니다. 문서 생성이나 계산 통과가 법원 제출·인가 또는 변호사의 승인을 뜻하지 않습니다.

## 개발 환경

Node 22.13 이상에서 `npm ci`, `npm run dev`로 실행합니다. 배포에는 D1 저장소와 R2 파일 보관소가 필요합니다. OCR 분류·추출·검증 모델은 `gpt-6.1-terra`이고 상담·법률 검토·법령 감시는 `gpt-6-luna`를 유지합니다. 키는 배포 환경에서 설정합니다.

이 공개 디렉터리에는 의뢰인의 원본 서류, 개인 정보, 비밀 키, 비공개 정답 자료를 넣지 않습니다. 같은 저장소의 다른 프로젝트는 변경하지 않습니다.
