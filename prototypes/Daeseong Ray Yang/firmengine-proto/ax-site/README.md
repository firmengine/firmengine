# FirmEngine AX

의뢰인 상담과 제출자료를 사건별로 정리하고, 원문 확인·개인회생 계산·법률 검토·법원 제출용 문서 초안과 담당자/변호사 검수까지 연결하는 업무 공간입니다.

**현재 main 코드는 계속 수정 중이며 최신 판본의 제품 인수/운영 배포는 미확인입니다.** 구현현황, 누락과 충돌, 수용시험, 과거 이력을 하나로 정리한 [제품 인수 통합 보드](docs/PRODUCT_RELEASE_INTEGRATION_BOARD.md)를 먼저 확인하세요.

## 가능한 업무

1. 상담 내용으로 사건과 준비 서류를 분류하고, 누락되거나 확인해야 할 사항을 담당자에게 표시합니다.
2. 서류별 원문·페이지·단수/복수 행·기간·금액·증거 위치를 보존하고 사실 승인과 원문 인식을 구분합니다.
3. 소득·채무·재산·생계비를 검증된 자료와 기준정보로 계산하되 불명확하거나 상충하는 결과는 확정하지 않습니다.
4. 법률 검토와 담당자/변호사 승인을 거쳐 신청·변제·보정 관련 문서의 검토용 초안과 수정 이력을 관리합니다.

## 실행과 검증

Node.js 22.13 이상. `npm ci`, `npm run dev`. 별도 검사: `npm run check:source`, `npm run check:product`, `node scripts/run-preapproval-regressions.mjs --full`.

`check:product`는 85종 문서, 693개 canonical 원천 피처, 18개 계산 모듈, 95개 위험 체크 등 **정적 계약의 무결성**을 검사하며 법률·세무 적합성이나 실제 배포 완료를 뜻하지 않습니다. 실제 사용에는 운영 D1/R2, 공식 법원 서식/시행일, 변호사 최종 검수와 격리 E2E 인수가 별도로 필요합니다.
