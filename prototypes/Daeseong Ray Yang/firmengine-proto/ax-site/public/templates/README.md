# 편집형 법원 서식

기본 6종과 사건별 부속표·조건부 신청서를 포함해 18개 DOCX 템플릿을 제공합니다. 함께 보관한 법원 공개 PDF/HWP의 구역·항목을 편집 가능하게 재구성한 초안입니다. 원본과 동일한 페이지 배치나 최신 접수 적합성을 보장하는 변환본이 아닙니다. 실제 법원에서 받은 양식과 필드 매핑을 검토한 뒤 사용합니다.

| 구분 | 템플릿 | 선택 기준 |
| --- | --- | --- |
| 기본 제출서류 | D5100·D5106·D5101·D5103·D5105 | 기본 사건 패키지 |
| 변제계획안 | D5110 / D5111 | 가용소득 / 명시적으로 검토한 가용소득+재산처분 계획 |
| 채권자 부속명세 | ANNEX_SECURED·DISPUTED·ASSIGNMENT·OTHER | 담보·다툼·전부명령·기타 상세가 있는 경우 |
| 변제예정액표 | PAYMENT_SCHEDULE | 확정·미확정 원금, 월·총 지급/유보, 재산처분 배분 |
| 보조 부속표 | ASSET_VALUATION·EVIDENCE_INDEX | 재산별 평가와 실제 편철 증빙 대조. 독립된 공식 전산양식으로 주장하지 않음 |
| 조건부 신청·제출서 | D5108·D5109·D5113·D5114 | 현재 사건 버전에 대한 명시적 법률 검토 후 해당 서식만 생성 |

- `originals/`: 출처 카탈로그의 SHA-256과 대조하여 보관한 공개 빈 원본. 실제 의뢰인의 자료나 제출본을 포함하지 않습니다.
- `catalog.json`: 원본 URL, 수집일, SHA-256, 템플릿 버전·해시, 매핑된 필드와 검토 상태.
- `additional_sources.json`: 2026-10-26 공식 양식 목록에서 받은 D5108·D5109·D5111·D5113·D5114 공개 PDF/HWP 10개의 출처와 해시. 원본 내 기재례는 사건 사실로 사용하지 않습니다.
- `../rules/court_package.json`: 법원 출력서류 정의. 입력 증빙 검증과 별도로 생성파일·편철 첨부·서명·조건부 신청의 상태를 관리합니다.
- `*.docx`: `{{client_name}}` 같은 단순 토큰. `{{creditor.*}}`, `{{asset.*}}`, `{{month.*}}` 행은 실제 자료 수만큼 반복됩니다.
- `build_templates.py`: 이 디렉터리에 보관한 원본과 카탈로그에서 편집형 템플릿을 다시 만드는 개발 도구. 외부 참고 프로젝트에 의존하지 않습니다. 재실행하면 템플릿 편집 내용이 덮어써지므로 변경한 양식은 먼저 보관해야 합니다.

토큰은 코드나 표현식으로 실행하지 않습니다. 누락은 `[확인 필요]`, 충돌은 `[불일치·확인 필요]`, 여러 기간을 하나로 정할 수 없으면 `[기간 선택 필요]`로 남깁니다. 서명·동의·법률 판단 선택란은 자동 확인하지 않습니다. 동일 채권자의 여러 기간을 합산하거나 36개월을 기본값으로 채우지 않습니다.

템플릿을 변경하면 대응 항목을 검토한 뒤 `catalog.json`의 템플릿 버전과 SHA-256도 갱신해야 합니다. 해시가 달라진 파일은 렌더러가 거부합니다. 각 출력본에는 별도 출처·검토 대조표가 붙습니다. 채권자별 배분은 출처·현재 버전이 연결된 `plan_allocations` 결과만 기재하며 원금 비례로 추측하지 않습니다. D5111은 공통 계획 본문과 처분 별표를 확장한 재구성이므로 원본 전체 조항과의 대조가 필요합니다.

`court_package(snapshot)`은 `GENERATED_FORM`, `EVIDENCE_ATTACHMENT`, `MANUAL_SIGNATURE`, `CONDITIONAL_APPLICATION`을 구분합니다. 파일을 만들었다는 사실만으로 내용 완성·서명 완료로 표시하지 않습니다. 조건부 서식은 `package_decisions[key]={value:true,state:'VERIFIED',revision,reviewer}`가 현재 버전일 때 선택합니다. 증빙은 `court_attachments`에 포함 확인해야 하며 업로드만으로 편철 완료가 되지 않습니다. 완성본 검토는 `package_reviews`, 실제 서명본 확인은 `package_signatures`로 별도 관리합니다. 필수 기재값·배분근거·평가 항목이 없거나 템플릿이 없으면 생성 전 차단합니다. 파일 부재 자체와 서명·편철 확인은 생성 후 패키지 완성 단계에서 확인합니다.

XLSX의 금액과 산식은 값·정밀도·출처 보존을 위해 텍스트로 기록합니다. 외부 문서에서 온 `=...` 문자열을 엑셀 수식으로 실행하지 않습니다. 출력물을 외부에서 수정한 내용은 앱의 검토 승인에 자동 반영되지 않습니다.

## 공개 소스 배포 범위

이 배포에는 실행용 빈 DOCX와 매핑 메타데이터를 포함합니다. 법원 원본 PDF/HWP의 복제본은 제외하며, catalog.json과 additional_sources.json의 공식 다운로드 URL·해시를 참조하세요.
