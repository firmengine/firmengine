1. **증권 전용 검토 후보 누락:** #610~620 `securities_balance::...`는 공유 `securities_balance` 문서에서 실제 family가 `cash_deposit_asset`으로 라우팅된다. 현재 `reviewScope(family)`는 `SEOUL-408` 후보를 11개 모두 반환하지 않는다. 이미 [Draft PR #56](https://github.com/firmengine/firmengine/pull/56)이 canonical namespace를 추가해 해결을 제안하고 있으나 main 미병합, 공식 근거·변호사 승인·Node CI 미인증이므로 **중복 코드를 덮어쓰지 않음**. 이는 검토 후보 공백이며 법률상 필수요건 누락 확정이 아니다.
2. **증권 확장 적용조건 11건 미등록:** #610~620이 인덱스·공유문서 OCR 원천 계약에는 있지만 `field-applicability-contracts.json`의 `cash_deposit_asset` family 목록에 없음(0/11). 추가필드 등록 정책인지 검토가 선행되어야 한다. 관련 미등록/미승인 요건 **0% 합격**, 자동 의무화·삭제 금지.
3. **담보 금액과 원화 자동합산/이중차감 경계:** #601 `actual_payoff`는 `context_only`로만 직접 선언, #606 `registered_maximum`은 등기 채권최고액이지 실제 잔액 아님. #601, #606 각 2문서 source slot은 2개 채무가 아님. 담보권 순위 #605·권리자 #608·설정자 #604·담보 ID #602·해지/등록일 #603/#607을 동일 권리·대상·시점으로 대조 전 청산가치 차감/원화 합산 금지.
4. **증권 현재고의 수량/통화/미결제 구분:** #612 `cash_balance`, #613 `quantity`, #614 `quantity_unit`, #618 `unsettled_liability`, #619 `valuation_currency`, #620 `valuation_datetime`는 모두 **source-only**. 보유 수량은 원화가 아니며 외화·매도대금·미결제 채무·중복 계좌별 명의 확인 없이 `asset.grossValue`로 자동 전환 금지. 은행잔액·증권 예수금과 동일 원천이면 이중계상 위험. 실제 잘못된 산식은 재현하지 않았음.
