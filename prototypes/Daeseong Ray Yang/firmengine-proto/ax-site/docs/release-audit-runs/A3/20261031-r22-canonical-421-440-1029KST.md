2. **P2 지방세 일반 법률·서식 후보 누락 가능성**: reviewScope(local_tax)는 EVIDENCE_INDEX만 반환하고 채무 family처럼 D5106/D5110 후보를 만들지 않음. 정적 라우트 미연결 확인이지 법원이 특정 서식 제출을 요구한다는 확정이 아님. 세목·체납/부과/비용·우선채권 여부를 공식 근거와 변호사가 검토해야 함.
3. **소송금액 혼용 위험**: #422 claimed_amount/#427 judgment_amount/#424 enforced_amount는 총액 3개로 합산 금지. #428 parties, #429 security_or_attachment, #430 status, #425 event_date, #426 issue_date, 앞선 #420 case_id와 원천 사건·당사자·일자 연결 확인 필요.
4. **지방세 금액 중복·기준일**: #436 arrears, #438 assessed_amount, #440 collection_cost, #437 as_of_date, #439 authority를 각 세목·기준일·납부상태에 따라 분리. 임의 원화합산 금지.
5. **계약조건 금액 오인**: #431 이율/주기, #433 상환회수, #435 예정납입은 현재 원금이나 실제 입출금·생활비가 아님. 원 단위 보존하며 검산/역질문으로만 사용.
