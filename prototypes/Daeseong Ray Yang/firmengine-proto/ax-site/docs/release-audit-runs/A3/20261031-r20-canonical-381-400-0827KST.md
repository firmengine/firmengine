3. **상속 사실과 법률효과 분리.** #381 법원 접수·결정문 참조, #382~384 상속인·관계·재산 ID, #385 분할일, #386 원문 지분(`source fraction`), #387 상속개시일은 각기 다른 증빙이다. 지분값·상속재산을 자동 소유확정·원화청산가치로 합산하거나 포기/한정승인 법적 효과를 추측 금지. 증거·검산·역질문·필요 법적 근거 확인 큐에 유지.
