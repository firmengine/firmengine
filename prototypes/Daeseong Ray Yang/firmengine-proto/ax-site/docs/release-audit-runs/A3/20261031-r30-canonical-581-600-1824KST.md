## P2 검토 후보 (실제 오류 단정 금지)
1. **확장 canonical 적용조건 19 ID·26 슬롯 미등록**: #582~600의 부가 서류·family 확장필드는 canonical 등록·원천 사용은 있으나 family 적용조건 목록에 없다. #581만 1/1 등록. 별도 확장 적용 정책이 의도인지 먼저 검증. 무단 필요조건 강제 추가/삭제 금지.
2. **기간 역할의 비대칭**: #591 `resident_registration::residence_history_period`는 `datatype=period`지만 `temporal_role=not_applicable`이어서 원본 `hasPeriod=false`. 반대로 #593/#594/#596(퇴직분류·이력), #597(사용자 서명상태), #599/#600(급여 금액) 등 비기간 6개는 family regex로 `true`. 원본 함수의 실제 분기 결과이며 실제 사건 오경고/누락 재현은 아님. [기존 Draft PR #51](https://github.com/firmengine/firmengine/pull/51)과 역할 충돌 검토 필요.
3. **급여 증빙 대체 시 서명 Fact 연결 검토**: [`substitution-policy.json`](../../lib/substitution-policy.json)의 4개 서울/부산 원천징수→급여확인서(+통장) 갈음 경로는 `employerSignatureRequired`. `approve-document-substitution.ts`의 `employerSigned:boolean`은 사람 검토자가 제공하고 proof Fact fingerprint를 기록하지만 #597 `employer_confirmation_status` 또는 #598 `employer_signature_date`를 boolean과 **직접 정합 대조하는 코드**는 이 경계에서 발견되지 않음. `document-substitution.ts`는 사람·원문·연결 조건을 별도로 검사하므로 실제 갈음 우회라고 단정 금지; 서명 출처 연결과 부정 회귀는 추가 검토.
4. **급여 총액·공제와 월소득**: #599/#600은 #461 실수령액·귀속월·계좌입금 확인 없이 법원 인정 월소득으로 자동합산 금지. 정확 typed 2개와 내부 D5103 토큰이 존재해도 실제 18 계산 수행·승인·공식 서식 일치는 미관찰.
5. **채권·퇴직금·시가 source-only의 증거 가치**: #582 회수액은 채권 현재가치/원금과 다르고, #583~588 동일 7개 ID가 business_assets_liabilities/litigation_enforcement 2 family에서 **14 슬롯**이라고 채권 2건이 아니다. #592~596 퇴직추정일/상품/조건/기간/이전이력은 현금화된 자산이 아니다. `reviewScope(pension_contribution_benefit)`는 EVIDENCE_INDEX만 반환(재산 서식 직접 후보 없음), 법률·재산 검토가 필요. 0개 소비처=무용/0원 아님.
