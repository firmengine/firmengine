## 발견 결함 후보: 기간 비해당 필드에 소스 기간 요구 플래그

원본 `lib/feature-lineage-audit.ts`의 `hasPeriod(role,family)`를 실제 V8에서 실행했다. **독립 기대**: 타입이 식별자/상태/소득 종류/지급자·수령자이며 `temporal_role=not_applicable`인 필드에는 **해당 필드 자체의 필수 기간을 부과하지 않는다**(요구서류 전체 기간 및 관련 금액·날짜 증빙은 별도). **실제 관찰**: `bank_transactions` 또는 `current_nonwage_income` 이름에 대한 정규식 때문에 아래 **6개가 `periodIdentity=true`**로 평가된다.

- #262 `crypto_transactions::source_address`: source temporal `not_applicable`, datatype `identifier`, 현재 periodIdentity **true** (독립 기대 false).
- #263 `crypto_transactions::transfer_status`: source temporal `not_applicable`, datatype `category`, 현재 periodIdentity **true** (독립 기대 false).
- #264 `crypto_transactions::txid`: source temporal `not_applicable`, datatype `identifier`, 현재 periodIdentity **true** (독립 기대 false).
- #272 `current_nonwage_income::income.other.income_kind`: source temporal `not_applicable`, datatype `enum`, 현재 periodIdentity **true** (독립 기대 false).
- #274 `current_nonwage_income::income.other.payer`: source temporal `not_applicable`, datatype `party_role`, 현재 periodIdentity **true** (독립 기대 false).
- #276 `current_nonwage_income::income.other.recipient`: source temporal `not_applicable`, datatype `party_role`, 현재 periodIdentity **true** (독립 기대 false).

이는 **실제 법률 판정이나 사건 차단이 발생했다는 증거가 아니라 정적 플래그 기반의 거짓 경고 후보**다. #265 단가는 금액형이며 거래기간/체결시점 검토가 필요할 수 있어 6개 후보에 포함하지 않는다. 이미 미병합 [Draft PR #51](https://github.com/firmengine/firmengine/pull/51)이 `hasPeriod`에 datatype 조건을 추가하는 수정을 포함하는 것을 실제 PR patch로 대조했다. **중복 신규 코드 PR을 만들거나 기존 에이전트 파일을 덮어쓰지 않았다.** PR #51의 87개 전반 영향과 #262~264/#272/#274/#276의 실 Node 회귀·타 PR 보존 병합·서류담당자/계산사무장 확인 전 **미수정·미승인**이다.
