# v44 변경사항

2026-10-29 배포. v43 작업본을 이어서 수정했습니다. 기존 사이트·저장소·키·모델·비공개 접근 범위는 유지했습니다.

## 이번에 보완한 기능

- 같은 저장 요청을 재시도해도 중복 변경을 만들지 않도록 정리했습니다.
- 동시에 수정했거나 저장 후 결과 조회가 늦어지는 상황을 구분했습니다.
- 사실 정정·철회가 계산 자료와 담당자 검토 상태까지 이어지도록 수정했습니다.
- 상담 결과, 준비 서류, 제출 자료, 담당자 작업을 연결했습니다.
- 월별 변제 예산·채권자 배분·서류 합계를 같은 기준으로 대조합니다.
- 상충하는 법률 검토 결과를 근거와 함께 표시합니다.
- 문서 필수값과 최종 작성 조건을 확인하고, 반복 편집·재생성 충돌을 처리합니다.
- 기준 변경의 승인·영향 확인·복원과 실패 작업의 확인·재시도 경로를 추가했습니다.
- 기존 사건은 변경 내용을 먼저 확인한 뒤 새 업무 형식으로 전환할 수 있습니다.

## 마지막 통합 점검에서 고친 오류

- 사실을 철회하면 현재 값 목록에서 사라져 저장이 실패하던 문제
- 사실 금액을 고친 뒤 계산 객체에 이전 인정 상태가 남던 문제
- 같은 문구를 여러 번 수정하면 스스로 충돌로 잡히던 문제
- 배분되지 않은 예산을 합계 오류와 혼동하던 문제
- 보정 제출을 근거 없이 기록할 수 있던 문제

## 남은 확인

950개 테스트 통과가 모든 실제 업무의 인수 완료를 뜻하지는 않습니다. 공식 전자소송 서식 대조, 실제 담당자의 전체 화면 사용, 실제 저장소 장애 상황, 기관별 세부 예외는 계속 확인해야 합니다. 이번 작업에서 OCR 재평가나 유료 법률 보조판단 평가는 실행하지 않았습니다.
