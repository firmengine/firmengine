# 기준정보 관리

적용 기준은 제안, 검토, 승인, 적용을 구분합니다.

- 적용일과 관할이 맞는 기준인지 확인합니다.
- 미래에 시행되는 기준을 현재 사건에 자동 적용하지 않습니다.
- 변경 제안은 권한을 지정받은 사람이 검토합니다.
- 검토 도중 제안이나 기존 기준이 바뀌면 다시 확인합니다.
- 영향을 확인할 사건을 명시적으로 선택합니다. 관계없는 사건과 기존 문서를 일괄 변경하지 않습니다.
- 이전 기준으로 돌아갈 때도 기존 이력을 지우지 않고 복원 기록을 남깁니다.

기본 설정은 지정된 담당자의 승인입니다. 별도의 두 사람 확인 정책이 설정된 경우에만 추가 검토자를 요구합니다. 기준 승인은 개별 사건의 사실·법률 검토 승인을 대신하지 않습니다.
