# 업무 흐름

1. **사건과 상담을 확인합니다.** 상담 결과를 해당 사건에 연결하고 필요한 서류 목록을 검토합니다.
2. **자료의 대상과 기간을 연결합니다.** 누구의 자료인지, 어느 기간인지 확인합니다. 같은 서류가 여러 항목을 뒷받침할 수 있습니다.
3. **추출값을 원문과 대조합니다.** 틀린 값은 정정하고, 읽을 수 없는 값·충돌·누락은 그 상태로 남깁니다.
4. **계산 결과를 확인합니다.** 소득·생계비·채무·재산과 월별 변제 예산을 확인합니다. 가용소득과 일반채권에 실제 배분할 월 예산은 서로 다릅니다.
5. **남은 작업을 처리합니다.** 대상이 모호한 자료, 부족한 기간, 법률 검토 항목, 상충하는 판단을 담당자 작업에서 확인합니다.
6. **초안을 작성합니다.** 현재 사건 값으로 필요한 문서를 생성하고, 반복 표의 행·합계·미확정 표시를 대조합니다.
7. **검토 조건을 충족한 뒤 최종 작성합니다.** 증빙 확인과 필요한 담당자·변호사 검토가 끝나야 합니다. 값이 바뀌면 관련 검토를 다시 진행합니다.
8. **실제 절차는 별도로 기록합니다.** 법원 제출·접수·보정 등은 확인한 문서와 날짜를 연결해 기록합니다. 이전 출력물은 덮어쓰지 않습니다.

저장 응답이 늦어지면 같은 요청을 다시 확인하세요. 새 요청으로 중복 저장하지 마세요. 다른 담당자가 먼저 변경했다면 최신 내용을 불러와 비교합니다.

현재 합성 평가 사건은 계산과 문서 동작을 확인하는 자료입니다. 사람의 검토를 대신 승인하거나 실제 제출 사건으로 바꾸지 않습니다.
