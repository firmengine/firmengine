# 분류 복구·진술 연결·평가일 점검

## 문서 분류 복구

역할이 미확정된 페이지는 최초 분류 결과가 증빙 또는 불명일 때 한 차례 추가 분류를 요청할 수 있다. 원본, 상단 확대, 전체 페이지 회전 보기를 비교한다. 두 후보가 모두 저장되기 전에는 추가 모델 호출을 사용하지 않는다. 시도 수는 호출 전에 저장하며 최대 두 번의 분류 호출 뒤에는 검토 요청으로 종료한다.

역할 복구에는 원문 표제 또는 발행주체와 문서 구조 인용이 함께 필요하다. 이 관측은 라우팅 근거이며 값·신원·법률 인정이나 원문 검증 기록이 아니다. 제출본·관리자료는 기존 원본 hash 기반 제외 규칙을 유지한다. 미확정 페이지에는 분류 복구 계획에 해당하는 후보만 허용하고, 일반 추출 복구를 허용하지 않는다. 후보는 원본·기준 이미지·계획 ID·위치·회전에 결합한다.

급여명세 유형의 국문·영문 별칭을 통합하고 지급총액·공제총액·실지급액·귀속기간을 별도로 추출하도록 안내한다. 파일명은 분류 근거가 아니다.

## 신청인 진술 연결

진술 문단의 record 번호만 달라졌다는 이유로 연결을 막는 문제를 수정한다. 연결은 원문에서 신청인인 작성자, 같은 작성자의 신청 의사와 서명, 같은 진술 구간이 명시적으로 연결될 때만 허용한다. 단일 문단도 같은 작성자 근거를 요구한다. 다른 작성자·불명확한 구간·상충·철회는 자동 결합을 막는다. 사용자 입력 진술은 보존하며 자동 진술은 최신 원장에서 파생한다.

여러 페이지의 진술은 명시적인 연속성 연결이 구현되기 전까지 자동 합치지 않는다. 원문이 불명확하면 서식의 완성도를 높이기 위해 작성자를 추정하지 않는다.

## 재산 평가 기준일

재산 평가일이 없거나 실제 날짜가 아니면 해당 재산 기여액 계산을 보류한다. 유효한 날짜가 사건 산정기준일과 다르면 계산 가능한 금액은 검토용으로 유지하되 청산가치 비교를 확정하지 않고 최종 확정 경로를 차단한다. 전체 재산가치 검토 체크박스만으로 이 개별 날짜 불일치를 해소할 수 없다. 임의의 최근 N일 기준 또는 새로운 법률요건을 도입하지 않는다.

## 독립 감사에서 남은 문제

- 현재 검수 API는 로그인 계정과 생성본 지문을 기록하지만 담당자/변호사 역할의 전문 자격을 확인하지 않고 같은 계정의 두 단계 확인도 허용한다. 이를 독립된 두 사람의 검수로 해석하면 안 된다.
- 생성 파일 저장 뒤 사건 revision 비교가 실패하면 현재 manifest에 연결되지 않는 생성 파일이 남을 수 있다. 오래된 생성물을 현재 승인본으로 만들지는 않지만 정리 정책이 필요하다.
- 내부 감사 부속표와 제출용 파일의 구성 분리, 실제 공식 서식의 빈 항목, 여러 페이지 진술 연속성 및 전체 내용 평가 매핑은 별도 개선 대상이다.

## 검증 해석

코드 회귀검사, 모델 실호출, OCR 지정 필드 일치, 페이지 완료, 공식 서식 내용 일치, Office 물리적 보존은 각각 별도 지표다. 어떤 코드 검사 통과율도 다양한 실제 사건의 최종 문서 99% 정확도를 뜻하지 않는다. 정답·평가 입력·분모는 개발 결과에 맞추어 변경하지 않는다.
