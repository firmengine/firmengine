# 상담과 준비 서류

상담 결과를 사건에 채택하면 필요한 서류 목록과 확인 작업이 연결됩니다.

- 서류마다 대상, 기간, 목적과 필요 여부를 확인합니다.
- 대상이 모호하면 사람이 연결할 때까지 미확정으로 둡니다.
- 같은 문서를 여러 요구 항목에 연결할 수 있습니다. 원문 사실은 복제하지 않습니다.
- 자료가 도착했다는 사실과 필수값까지 확인됐다는 상태를 구분합니다.
- 기간 일부만 있거나 읽을 수 없는 필수값이 있으면 확인 필요로 남습니다.
- 제외·비해당 판단에는 담당자와 사유·근거가 필요합니다. 법원이 요구한 자료를 임의로 면제하지 않습니다.
- 확인한 자료가 바뀌면 기존 확인을 다시 검토합니다.

사용 순서는 [업무 흐름](workflow.md)을 참고하세요.
