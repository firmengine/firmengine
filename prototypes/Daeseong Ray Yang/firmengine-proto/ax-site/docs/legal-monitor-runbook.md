# 법령·법원 변경 점검

법령, 법원 안내, 서식의 변경 가능성을 확인하고 검토 후보를 만듭니다. 변경 후보를 바로 적용하지 않습니다.

화면의 상태를 다음처럼 구분합니다.

- **설정됨:** 점검하도록 설정한 상태
- **실행 확인:** 실제 일정 실행이 확인된 상태
- **일시 중단·미확인:** 실행이 보장되지 않는 상태
- **일부 확인·실패:** 자료 수집을 끝내지 못한 상태
- **변경 후보:** 담당자가 내용과 적용 시점을 확인해야 하는 상태

수집 실패는 변경 없음으로 기록하지 않습니다. 마지막 정상 확인 자료를 보존합니다. 본문이 같아도 첨부 서식이 달라지면 따로 확인합니다.

이번 배포에서 기존 일일 점검 일정을 새로 켜거나 변경하지 않았습니다.
