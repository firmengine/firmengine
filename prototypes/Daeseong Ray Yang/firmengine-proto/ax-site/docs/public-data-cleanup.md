# 공개 저장소의 사례 자료 정리

2026-10-29에 이전 프로토타입과 재시도용 프로토타입까지 확인했습니다.

- 실제 샘플 PDF의 페이지 분리표, 기준표, 사례별 평가 결과와 실행 기록을 삭제했습니다.
- 문서·스크립트에 남아 있던 해당 샘플의 페이지 구성과 고정 평가 정보를 제거했습니다.
- 앱의 실제 사건 식별자는 일방향 확인값으로 바꿨습니다. 원본 보호 동작은 유지합니다.
- 개별 평가의 입력·결과는 Git에서 제외된 작업 폴더로 옮기도록 코드를 변경했습니다.
- 합성 테스트, 일반적인 법률·서식 기준과 공개 빈 양식은 유지합니다.

이 작업은 GitHub의 현재 파일을 정리한 것입니다. 운영 사건 DB와 배포 사이트의 자료는 변경하지 않았습니다. 과거 Git 커밋의 내용은 남아 있으며 이번 변경은 이력을 재작성하지 않습니다.

추가 반영 전에는 상위 프로토타입에서 `python scripts/check-public-case-data.py`를 실행하세요. 알려진 식별자와 사례 자료 경로를 검사하며, 새로운 자료에 대한 사람의 내용 검토를 대신하지 않습니다.
