# 문서 작성 조건

**초안**은 미확정 항목을 표시한 검토용 문서입니다. **최종 작성**은 현재 사건 자료와 필요한 검토 조건을 모두 확인한 뒤 가능합니다.

최종 작성 전에 확인할 내용입니다.

- 필수 서류의 대상·기간·필수값이 확인됐는지
- 원문 사실과 법적 인정이 필요한 만큼 검토됐는지
- 소득·생계비·재산·채무·변제 일정의 값과 합계가 맞는지
- 미배분 금액, 상충하는 법률 판단, 미해결 문서 편집이 남아 있는지
- 문서 생성 이후 입력이나 적용 기준이 바뀌지 않았는지

값이 바뀌면 관련 검토와 출력물을 다시 확인합니다. 이전 파일과 검토 이력은 보존합니다. 문서 생성은 법원 제출이나 인가가 아닙니다. 합성 평가 사건은 실제 최종 제출 대상으로 승인할 수 없습니다.
