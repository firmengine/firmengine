# 생성 문서 검산과 전자소송 제출 준비 상태

문서 생성의 값 일치와 전자소송 공식 양식 일치는 별도로 판정한다. 현재 DOCX는 공개 빈 양식의 항목을 편집형으로 재구성한 검토본이며, 계산·원문 근거 부록을 포함한다. `final`은 최종 **검토본**이라는 뜻이다. 법원의 전자서식과 동일한 배치, 업로드 적합성 또는 법적 승인을 인증하지 않는다.

## 변제계획안 산식

공식 D5110 PDF의 「2. 변제에 제공되는 소득 또는 재산」에 있는 7열 표를 기준으로 다음 관계를 검사한다.

| 열 | 의미 | 검산 |
| --- | --- | --- |
| ① | 월평균 수입 | 저장된 관측 월평균값 |
| ② | 월평균 생계비 | 저장된 생계비값 |
| ③ | 월평균 가용소득 | ①−② |
| ④ | 월 회생위원 보수 | 명시적으로 입력된 월액 |
| ⑤ | 월 실제 가용소득 | ③−④ |
| ⑥ | 변제 횟수 | 명시적으로 입력된 개월 수 |
| ⑦ | 총 실제 가용소득 | ⑤×⑥ |

출처는 [대법원 공개 D5110 PDF](https://file.scourt.go.kr/AttachDownload?path=004&file=1745818892115_144132.pdf&downFile=D5110.pdf&seqnum=) 2쪽이다. `public/templates/catalog.json`의 원본 SHA-256 `6bf54e0d45c2cb92da553bea33033d7da0a1b419fdc9b5ba60f789aec5a61532`와 대조할 수 있다. 구판 편람에 있는 다른 열 구성을 현재 원본보다 우선하지 않는다.

관측 소득을 표에 표시하는 행위는 소득을 법적으로 인정하는 행위가 아니다. 인정 전 상태와 누락은 그대로 유지한다. 음수는 부족액이며 음수의 변제안을 승인하지 않는다. 우선·재단채권을 고려한 일반채권 월 변제액과 ⑤는 서로 다른 값이므로 대체하지 않는다. 표시 단계에서 저장된 원 단위 정수에 추가 반올림을 적용하지 않는다.

생성한 DOCX를 다시 열어 실제 표의 세 산식을 정수 연산으로 검사한다. 값이 모두 있는데 산식이 맞지 않으면 파일 저장 전에 생성을 실패시킨다. 미확인 값이 있으면 검산 상태는 `unknown`으로 남긴다.

## 제출 준비 상태

`rendered.json`의 `filingReadiness`는 문서별 해시, 공식 서식 코드, 산식 상태, 미확인 표시, 내부 검토 부록의 존재를 기록한다. `EVIDENCE_INDEX` 등 내부 보조표는 공식 전산양식 코드로 표시하지 않는다. 현행 재구성 렌더러에서는 초안·최종 검토본 모두 `readyForElectronicFiling: false`, `officialParity: not_verified`이다. 원장이나 계산 검수가 끝났다는 이유만으로 이 상태를 제출 가능으로 바꾸지 않는다.

실제 제출용 출력을 구현하려면 현재 관할의 공식 원본 배치·항목·선택란·별지를 보존하는 렌더러, D5110/D5111 등 사건별 서식 선택, 내부 검토 부록과 제출 사본의 분리, 생성 파일 해시에 결합된 서식 대조 및 업로드 검증이 필요하다. 서명·날짜·미확정 사실·법적 판단은 담당자의 명시적 확인을 유지한다.

## 생성 무결성

- 저장된 계산·바인딩 스냅샷을 렌더링 중 변경하지 않는다.
- 업로드나 원장 CAS가 실패하면 그 요청이 만든 임시 객체·행만 정리한다.
- 원장 반영이 끝난 뒤 감사 로그가 실패한 경우 정상 생성물을 삭제하지 않는다.
- 합성 평가 사건의 최종본 생성 제한은 유지한다.
