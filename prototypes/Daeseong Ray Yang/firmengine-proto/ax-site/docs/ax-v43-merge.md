## 보존과 병합 범위

- 제공된 원본 파일 528개 모두 SHA-256·Git blob ID·크기를 검증했습니다.
- 원본과 줄바꿈만 다른 289개 파일은 기존 바이트를 유지했습니다.
- `.openai/hosting.json`의 기존 `DB`·`BUCKET` 바인딩과 MCP capability를 보존했습니다. 입력의 배포 프로젝트 ID를 이 체크아웃에 추가하지 않았습니다.
- 기존 n8n 정리 자료는 입력의 오래된 사본으로 덮지 않고 현재 v43 코드 기준으로 갱신했습니다.
- 보호 사건 해시, 일반화된 샘플 설정, 테스트 컨텍스트 격리와 Windows 호환 수정은 v43에도 유지돼 있습니다.
- 실제 사건 데이터·키·캐시·빌드 산출물과 비공개 샘플용 로컬 평가 실행기는 Git 커밋에서 제외합니다. 이전부터 수정 중인 평가 파일 3개도 이번 커밋에 포함하지 않습니다.
- 원본 입력 폴더는 그대로 두고, 병합 전 상태는 저장소의 `.local/backups/ax-site-pre-v43-20261029T032348Z.zip`에 보관했습니다.

현재 로컬 파일 해시와 병합 내역은 [v43 병합 manifest](ax-v43-merge-manifest.json)에 기록합니다. 이전 v35 manifest와 공개 소스 export manifest는 당시 이력으로 유지합니다.
