# Terra OCR 전환 - 코드 준비본

이 브랜치는 **배포/실행된 상태가 아닙니다** (2026-10-29). 기존 FirmEngine AX v44 운영 사건과 참조 데이터는 변경하지 않습니다.

- 신규 증빙 페이지의 분류, 추출, 원문 검증과 보정은 `gpt-6.1-terra`를 명시적으로 사용하도록 라우팅합니다.
- 상담 분류와 법률 검토는 기존 `gpt-6-luna`를 유지합니다.
- OCR 캐시와 검증 증빙에 모델을 명시하고, 기존 Luna 교차검증 기록을 가짜 Terra 결과로 바꾸지 않습니다.
- 합성 및 실제 샘플은 별도 평가 사건에서만 실행하고, 기존 작성된 신청서·변제계획안 등은 정답지로 분리하여 OCR 입력에서 제외합니다.
- API 키의 Terra 사용 권한, 배포 환경, 테스트와 실제 OCR 품질은 이 브랜치만으로 확인되지 않습니다.

실제 118쪽 샘플 내용과 비밀키는 공개 Git에 넣지 않습니다. 99% 정확도와 법원 인가는 별도 독립평가 대상입니다.

## OCR 결과 3분류 이상 원칙 (합성 테스트 검증)

- **누락**: 소스에 실제 필드나 행이 있으나 추출되지 않았다는 원문 인용 및 위치가 있는 경우에만 `source_omitted`. 단순 서식 피처 미출력은 `not_observed`이며 누락으로 확정하지 않습니다. 필요한 제출서류 미도착은 별도 `missing_document`입니다.
- **오인식**: 독립 대조가 값·단위·필드 의미를 정정하거나 불일치로 지적한 경우 `misrecognized`. 정정 후보 여부를 함께 표시하고 자동 법적 인정하지 않습니다.
- **해당 없음**: 문서에 명시된 비해당 표현과 인용·위치가 모두 확인된 경우에도 `not_applicable_source_claim`로만 표기합니다. 의뢰인 진술이나 빈칸, 0원으로 확정하지 않습니다. 서류 요구사항은 별도의 담당자 검토를 마쳐야 `not_applicable_confirmed`입니다.
- 추가 상태는 `unreadable`(마스킹·판독불가), `source_blank`, `conflict`, `pending_verification`, `not_observed`, `read_supported`입니다. 원문 증빙, 계산 적용, 법률 인정, 최종 작성 권한은 항상 분리합니다.

현재 브랜치에서 페이지 작업 GET(`/api/cases/{id}/process?jobId={pageJobId}`) 응답에 `ocrTriage`라는 **읽기 전용** 진단 필드를 추가합니다. 모델·원본 증명 연결이 없다면 진단을 미검증으로 표시합니다. 모델 실호출·사이트 배포·118쪽 재OCR은 아직 확인하지 않았습니다.
