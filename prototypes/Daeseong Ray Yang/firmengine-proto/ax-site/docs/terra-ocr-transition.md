이 브랜치는 **배포/실행된 상태가 아닙니다** (2026-10-29). 기존 FirmEngine AX v44 운영 사건과 참조 데이터는 변경하지 않습니다.

- 신규 증빙 페이지의 분류, 추출, 원문 검증과 보정은 `gpt-6.1-terra`를 명시적으로 사용하도록 라우팅합니다.
- 상담 분류와 법률 검토는 기존 `gpt-6-luna`를 유지합니다.
- OCR 캐시와 검증 증빙에 모델을 명시하고, 기존 Luna 교차검증 기록을 가짜 Terra 결과로 바꾸지 않습니다.
- 합성 및 실제 샘플은 별도 평가 사건에서만 실행하고, 기존 작성된 신청서·변제계획안 등은 정답지로 분리하여 OCR 입력에서 제외합니다.
- API 키의 Terra 사용 권한, 배포 환경, 테스트와 실제 OCR 품질은 이 브랜치만으로 확인되지 않습니다.

실제 118쪽 샘플 내용과 비밀키는 공개 Git에 넣지 않습니다. 99% 정확도와 법원 인가는 별도 독립평가 대상입니다.

## OCR 품질 구분 규칙 (2026-10-29)

원문 재판독 결과는 `누락 의심`, `오인식·정정`, `오인식·미해결`, `원문상 해당 없음 주장`, `원문 공란`, `마스킹·판독불가`, `상충`, `미확인`을 별도로 표시합니다. 원문에 `해당 없음`이라고 쓰인 사실과 사건 법적 비적용 결론은 구분합니다. 빈칸·조회 자료 없음·미제출·가려진 수치를 0이나 비대상으로 변환하지 않습니다.

`GET /api/cases/{id}/process?jobId={jobId}`는 기존 보존 판독에서 유도한 `stored.sourceQuality`를 반환합니다. 이 값은 **정답 기반 정확도**가 아닙니다. 문서별 정확도는 별도 비공개 정답표를 검증한 후 `scoreIndependentOcr()`에서 계산하며, 동일 문서 SHA-256·쪽·피처·행 위치를 대조합니다. 보이는 값 대비 정확한 값의 비율과 해당 없음 판단 적중 건수는 서로 다른 지표입니다.

2026-10-29 로컬 보관 v43 호환 사본에서 테스트 34건 통과. 운영 v44의 전체 빌드·실제 Terra 호출·91쪽 OCR·DB 적재·배포는 **아직 검증하지 않았습니다**. 

### 독립정답 대조 보강

실제 원문에 값이 있는데 모델이 `해당 없음` 또는 `빈칸`이라고 출력하면 단순 누락이 아니라 **오인식**으로 분류합니다. 값이 일치해도 신청인·대상·기준일·대상 기간이 다르면 오인식입니다. 법원 작성서류가 섞인 118쪽 PDF는 증빙 91쪽과 정답 보류 25쪽을 구분합니다. 샘플별 독립 정답과 실제 Terra API 응답이 없으면 정확도는 `null`이며, 문서별 집계 역시 측정되지 않은 것으로 표시합니다.
