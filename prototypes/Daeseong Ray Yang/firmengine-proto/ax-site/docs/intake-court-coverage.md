# 상담 서류 85종 연결 보완 (2026-10-30)

**기준:** GitHub `main`의 `ax-site` 소스. 현재 기존 85종 중 상담 규칙에 없던 12종을 연결했습니다. 법원서식 제출과 실제 OCR 검증은 별도 단계입니다.

## 공신력 자료

- [서울회생법원 실무준칙 제402호](https://slb.scourt.go.kr/rel/information/qna/practice_rule.pdf): 제2조(신청 시 첨부), 제3조(법원이 추가 명할 수 있는 자료).
- [부산회생법원 실무준칙 제402호](https://bsb.scourt.go.kr/bsb/info/info_01/practice_rule_bsb.pdf): 동일하게 제2조와 제3조 구별.
- [개인회생사건 처리지침(재민 2004-4)](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2200000108651): 서류확보·추가제출·관할 실무 준칙 함께 확인.

법원별 지침은 변경될 수 있습니다. 특정 법원의 규정으로 전국 공통 제출의무를 만드는 것은 금지합니다.

**중요:** 12종은 16개 신규 규칙으로 연결했습니다. 기존 49개 상담 특성에 `asset.cash_on_hand` 1개를 추가하여 50개, 상담 규칙은 54개에서 70개입니다. 기존 서류 ID는 유지합니다.

## 적용·검증 및 남은 확인

- `lib/intake-court-coverage.ts`에서 신규 규칙을 선언하고 `lib/intake-catalog.ts`에서 기존 시드에 합칩니다.
- 운영 저장소에 기존 판본이 저장되어 있으면 `supplementIntakeCatalog`가 누락된 피처·규칙 ID만 새 불변 버전으로 추가합니다. **기존 사용자가 수정한 ID의 규칙·명칭을 덮어쓰지 않습니다.**
- 새로운 규칙이 반영되면 이전 상담 분석은 새 판본으로 재분석해야 합니다.
- `tests/intake-court-coverage.test.ts`에 85종 연결·서울/부산 분기·무조건 미요구·중복·기존 판본 보존 검사를 추가했습니다.
- 이번 커밋은 GitHub 소스 반영이며 **운영 DB 업데이트/사이트 배포나 실제 모델 호출을 진행하지 않았습니다.**
- 현재 main의 별도 파일에 병합 충돌 표시가 있어 전체 빌드와 통합 테스트 성공을 확인할 수 없습니다. 이 문제는 이번 상담 규칙 보완과 분리해 복구해야 합니다.
