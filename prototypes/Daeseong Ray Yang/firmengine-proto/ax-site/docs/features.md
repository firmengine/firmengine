# 기능 목록

기준: v44. 자동 계산과 사람의 확인을 구분합니다.

| 주요 기능 | 할 수 있는 일 | 주의할 상황 |
| --- | --- | --- |
| 사건 관리 | 사건별 자료·현재 값·변경 이력 확인 | 동시에 수정한 경우 최신 상태를 다시 확인 |
| 상담 | 상담 결과를 사건의 준비 서류 목록으로 채택 | 대상·기간이 불명확하면 추가 확인 |
| 서류 목록 | 필요 여부, 대상, 기간, 대체 자료, 제외 사유 관리 | 법원이 요구한 자료를 임의로 면제하지 않음 |
| 자료 연결 | 한 서류를 여러 요구 항목의 근거로 연결 | 자료를 중복 복제하지 않음 |
| 출처 보관 | 값과 원문 문서·쪽·인용을 함께 보관 | 마스킹·판독 불가·누락을 0으로 바꾸지 않음 |
| 사실 정정 | 원문을 대조해 값을 고치고 계산 자료에 반영 | 대상이 여러 개이면 자동 선택하지 않고 확인 작업 생성 |
| 자료 철회 | 철회 이력과 다른 남은 근거를 보존 | 과거 인정 상태를 해제하고 다시 검토 |
| 소득 계산 | 근로·사업·자산소득과 중복·기간 확인 | 확인되지 않은 기간이나 중복 소득은 별도 표시 |
| 채무 계산 | 원금·이자·담보·우선순위와 한도 확인 | 분류가 불명확한 채권은 법률 검토 필요 |
| 재산 계산 | 재산별 금액·공제·청산가치·처분 관련 금액 확인 | 재산 없음과 재산 자료 누락을 구분 |
| 변제계획 | 생계비, 수수료, 우선채권 등을 구분해 월별 예산과 배분 대조 | 배분되지 않은 금액과 부족한 금액을 숨기지 않음 |
| 법률 검토 보조 | 해당·비해당·미확정·충돌과 필요한 자료 표시 | 상충하거나 불완전한 결과를 검토 완료로 처리하지 않음 |
| 담당자 작업 | 담당자, 상태, 기한, 대기 사유 관리 | 같은 문제의 반복 작업을 합치고 새 근거가 오면 다시 확인 |
| 문서 작성 | 신청서·채권자목록·재산목록·수입지출목록·변제계획과 별지 생성 | 누락·합계 오류·검토 부족이면 최종 작성 차단 |
| 문서 편집 | 문구 수정, 재생성 시 변경 비교, 이전 파일 보존 | 금액과 사실은 원자료에서 수정; 충돌은 담당자 확인 |
| 기준정보 | 적용일·관할·변경 제안·승인·영향 확인·이전 기준 복원 | 제안만으로 적용하지 않고 승인 이력을 보존 |
| 변경 점검 | 법령·법원 안내·서식 변경 후보와 수집 실패 확인 | 설정됨, 실행 중, 일시 중단, 확인 실패를 구분 |
| 절차 기록 | 제출·접수·보정·인가·폐지·면책을 근거와 함께 기록 | 파일 생성만으로 법원 상태를 올리지 않음 |
| 권한·복구 | 편집·검토 권한 구분, 중복 저장 방지, 실패 작업 재시도 | 합성 자료와 보호 사건은 실제 승인·제출 대상으로 바꾸지 않음 |

법무법인 전체의 이해충돌 확인, 모든 법원별 예외, 공식 전자소송 서식의 완전한 일치는 별도 확인 범위입니다.
