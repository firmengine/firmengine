# 새로 수집한 공개 빈 서식과 편집형 초안

`originals/`는 2026-10-26 법원 공식 사이트에서 새로 받은 공개 HWP 6종입니다. 이전 프로토타입의 서식이나 제출 완료본을 사용하지 않았습니다. 출처 URL·원본 SHA-256은 `originals.json`, 필드 대응은 `catalog.json`에 있습니다.

| 원본 ID | 생성 내용 |
| --- | --- |
| D5100 | 개인회생절차 개시신청서 |
| D5101 | 재산목록 |
| D5103 | 수입 및 지출에 관한 목록 |
| D5105 | 진술서 |
| D5106 | 개인회생채권자목록·조건부 부속표 |
| D5110 | 가용소득에 의한 변제계획안·채권별 변제예정액표 |

`editable/`는 원본에서 확인한 항목과 절 구조에 대응하도록 새로 작성한 DOCX 초안입니다. 원본 HWP의 표 크기·쪽 배치가 그대로 보존되는 범용 변환기는 아닙니다. 공개 빈 서식을 받은 것과 사용자가 실제 받은 법원 요청양식의 대응 검수·전문가 승인은 구분합니다. 앱의 승인 입력은 로컬 검토 기록이며 운영 인증이 아닙니다.

채권자별 계약·원금·이자, 재산별 시가·담보·면제액, 소득원별 기간·수입·경비는 실제 본문 표에 반복 작성합니다. 확인되지 않은 주민번호·경력·가족·송달처·날짜 등은 추정하지 않고 `확인 필요`로 남깁니다. 원본에 포함된 기재 예시의 사건 값은 생성 입력으로 사용하지 않습니다.

프로젝트 폴더에서 편집형 빈 초안을 다시 만들려면 `python templates/build_templates.py`를 실행합니다. 공식 원본을 다시 받으려면 `python templates/fetch_originals.py`를 실행합니다. 원본을 바꾼 뒤 매핑을 검토하고 새 버전을 부여해야 합니다. `inspect_originals.py`는 공개 원본 문단을 읽기 전용으로 추출하는 도구입니다.

미리보기와 다운로드 파일은 `app/documents.py`의 같은 본문·표 모델로 만들어집니다. 생성 디렉터리는 덮어쓰지 않으며 패키지에 입력 버전·원본 해시·산식/서식 판본·개별 파일 해시를 기록합니다. 생성 당시 상태는 미검토 초안이며 실제 파일 해시별 검수는 API의 별도 기록입니다.
