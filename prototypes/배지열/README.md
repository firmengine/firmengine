# 빚오프 내부 업무공간 · 배지열

개인회생 사건 상담과 자료 검수를 위한 로컬 프로토타입입니다. office-review.html과 Basic 통합기획서의 사건 처리 순서를 참고했습니다. 기본 사건과 추출값은 합성 예시입니다.

## 실행

Node.js가 설치된 환경에서 이 폴더로 이동해 실행합니다.

```powershell
npm ci
npm start
```

브라우저에서 http://127.0.0.1:8092 를 엽니다. PORT 환경 변수로 포트를 바꿀 수 있습니다.

```powershell
npm test
```

기존 검수 상태·수정 사유·승인 무효화·역할 흐름 등의 테스트 11개가 포함되어 있습니다. 모든 OCR 문서와 화면 동작을 검증하는 테스트는 아닙니다.

## 구현한 기능

- 사건 등록: 이름·생년월일·전화번호·담당자 입력, 저장 및 검색
- 상담 이력: 상담 일시·방식·상담자·상대방, 요약과 상세 대화, 채무·소득·재산·가족·긴급 확인 사항
- 상담 자료: 카카오톡 텍스트·캡처·PDF·통화 녹음 업로드, 원본 보기·내려받기, 녹음 재생
- 상담 정리: 텍스트·PDF·사진에서 원문 문장을 찾아 정리 초안 생성, 출처 표시, 사람 검토 완료 및 수정 시 재검토
- 후속 업무: 담당자·기한·완료 여부, 다음 연락 일정, 상담 결과
- 자료 검수: 입력 증빙 43종과 대조용 자료 7종 체크리스트, 상태별 펼침 목록·이동, 검색과 필터
- 제출·검수 상태: 미제출 / 검수중 / 추가 검수 필요 / 검수 완료. 사유가 있는 적용 제외는 별도 관리
- PDF·사진 업로드 및 드래그 앤드 드롭, 첨부 목록, 페이지 이동과 원문 미리보기
- 자동 분류: 업로드한 전체 파일의 PDF 텍스트 또는 로컬 한글 OCR 결과로 서류 제목을 찾고, 체크리스트와 페이지를 연결해 항목 후보 입력
- 여러 서류가 들어 있는 원본의 인식된 종류별 페이지 묶음 생성, 판독·분류가 모호한 페이지와 누락된 항목 표시
- 원문·추출 항목·문서 요약을 하나의 카드에서 검수. 후보값 수정·확인·사유 있는 예외 승인
- 검수 확정, 수정 후 재승인, 변경 이력, 보정 요구·기한 기록, 화면 데이터 JSON 내보내기

## 저장 및 로컬 처리

화면 입력값은 현재 브라우저의 localStorage, 첨부 원본과 페이지 판독 결과는 IndexedDB에 보관합니다. 같은 주소에서 새로고침해도 유지되며 다른 브라우저·주소와 공유되지 않습니다. 브라우저 데이터 삭제 시 사라집니다. JSON 내보내기에는 첨부 원본이 포함되지 않습니다.

PDF.js, Tesseract.js와 한글 학습 데이터를 의존성으로 설치하고 로컬 서버에서 제공합니다. 앱 실행 중 문서나 녹음을 외부 AI API로 전송하지 않습니다. 의존성 설치에는 인터넷 연결이 필요합니다. 업로드한 문서·브라우저 데이터·node_modules는 Git에 포함하지 않습니다.

## 아직 연결하지 않은 기능과 한계

- AI가 의미를 분석하는 상담·문서 요약 및 상위 AI 모델 재분류
- 통화 녹음 자동 음성 전사
- Word 신청서 생성, 변제계획 계산
- 실제 로그인·서버 권한·SQLite·클라우드 공유

현재 자동 분류는 본문 제목과 표기 단서를 이용하며 추출값은 원문 문구의 후보입니다. 손글씨, 복잡한 표, 제목이 없는 페이지는 판독 또는 분류가 어려울 수 있습니다. 상담 정리 초안도 원문 문장을 모은 결과이며 AI 요약으로 표시하지 않습니다. 자동 입력값과 요약은 사람이 원문과 대조하고 확인해야 합니다. 역할 선택은 화면 체험용이며 실제 보안 경계가 아닙니다.

확정 스펙은 ../../docs/specs/배지열-서류OCR.md에 있으며 변경에는 배지열의 사전 승인이 필요합니다. 이 프로토타입은 전체 P0 구현 완료를 뜻하지 않습니다.
