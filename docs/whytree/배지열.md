## 목적과 업무

상위 목적에서 구체적인 업무 순으로 정리했습니다. 동일한 업무가 여러 목적에 연결되면 각 위치에 반복해서 표시했습니다.

- 행복한 삶 (개인)
  - 개인 일상 유지
    - 건강
    - 개인회생
      - 빚오프 플랫폼
      - 상담
      - 계약 및 수임료 확인
  - 회사 수익 창출
    - 개인회생
      - 빚오프 플랫폼
      - 상담
      - 계약 및 수임료 확인
    - 업무 자동화
      - 상담 AI 분석
      - 서류 OCR READ
      - 문서 및 DATA 검증
      - DB 구축
    - 큰사건 업무 수임
      - 계약 및 수임료 확인
- 회사 성장
  - 회사 수익 창출
    - 개인회생
    - 업무 자동화
    - 큰사건 업무 수임
  - 회사 홍보
    - 큰사건 업무 수임
    - 타 분야 확대
      - DB 구축

## 부가적인 목적

원본의 점선 화살표를 별도로 정리했습니다. 왼쪽 업무가 오른쪽 목적을 돕는 관계입니다.

| 업무 (how) | 부가적인 목적 (why) |
| --- | --- |
| 요청 접수 승인 | 개인회생 |
| 상담 | 건강 |
| 업무 관제 모니터링 | 업무 자동화 |
| 업무 관제 모니터링 | 큰사건 업무 수임 |
| 업무 관제 모니터링 | 타 분야 확대 |
| 업무 자동화 | 회사 홍보 |

## 변환 참고

- 실선은 가장 중요한 목적, 점선은 부가적인 목적을 나타냅니다.
- 원본에서 연결점에 고정되지 않은 세 화살표는 배치를 기준으로 `개인회생 → 개인 일상 유지`, `개인회생 → 회사 수익 창출`, `계약 및 수임료 확인 → 큰사건 업무 수임`으로 읽었습니다.
- 슬라이드 1의 「WhyTree 템플릿 사용법」은 작성 안내이므로 위 개인 WhyTree 내용과 구분했습니다.
